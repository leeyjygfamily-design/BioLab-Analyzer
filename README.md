# BioLab Analyzer
### 생명공학 데이터 분석 및 AI 기반 학습 지원 웹사이트

## 1. 프로젝트 소개

**BioLab Analyzer**는 생명공학 실험과 유전자 분석 과정에서 발생하는 데이터를 쉽고 효율적으로 분석할 수 있도록 제작한 Python 기반 웹 애플리케이션이다.

생명공학 분야에서는 DNA 염기서열 분석, 단백질 정량, PCR 프라이머 분석 등 다양한 데이터 처리 과정이 필요하다. 그러나 이러한 분석은 전문 프로그램이나 별도의 계산 과정을 요구하여 초보자가 접근하기 어렵다는 한계가 있다.

이를 해결하기 위해 Python과 Streamlit을 활용하여 여러 생명공학 분석 기능을 하나의 웹사이트에 통합하였다. 또한 Google Gemini API를 연동한 **AI 생명공학교사** 기능을 추가하여 사용자가 분석 결과를 이해하고 관련 생명공학 개념을 학습할 수 있도록 하였다.

### 개발 목적
- 복잡한 생명공학 데이터 분석 과정의 자동화
- DNA, 단백질, PCR 분석 기능의 통합
- 표와 그래프를 활용한 분석 결과의 시각화
- AI를 활용한 분석 결과 해석 및 생명공학 학습 지원

### 개발 환경
- **프로그래밍 언어:** Python
- **웹 프레임워크:** Streamlit
- **데이터 처리 및 시각화:** Pandas, NumPy, Plotly
- **생물정보학 분석:** Biopython
- **외부 API:** NCBI E-utilities API, Google Gemini API
- **개발 및 배포:** GitHub, Streamlit Community Cloud

## 2. 사용법

### ① 웹사이트 접속

아래 링크를 통해 BioLab Analyzer에 접속한다.

**웹사이트:** https://biolab-analyzer.streamlit.app/

별도의 프로그램 설치 없이 웹 브라우저에서 분석 기능을 사용할 수 있다.

### ② 분석 기능 선택

웹사이트의 메뉴에서 원하는 분석 기능을 선택한다.

- **DNA 분석:** 유전자 검색, 염기서열 분석, ORF 탐색, 변이 분석
- **BCA 단백질 정량:** 흡광도 데이터를 활용한 단백질 농도 계산
- **PCR 프라이머 분석:** 프라이머 특성 및 예상 증폭 산물 분석
- **AI 생명공학교사:** 분석 결과 해석 및 생명공학 관련 질문

### ③ 데이터 입력 및 분석 실행

**DNA 분석**
1. 분석할 유전자명과 생물 종을 입력한다.
2. NCBI 검색 결과에서 원하는 DNA 서열을 선택한다.
3. GC 함량과 DNA 길이를 확인한다.
4. ORF 분석 또는 변이 분석을 실행한다.
5. 필요에 따라 DNA 분석 결과를 PCR 분석이나 AI 생명공학교사로 전달한다.

**BCA 단백질 정량**
1. 표준용액의 농도와 흡광도 데이터를 입력하거나 파일을 업로드한다.
2. 표준곡선과 선형회귀 분석 결과를 확인한다.
3. 미지 시료의 흡광도 데이터를 입력한다.
4. 계산된 단백질 농도와 분석 결과를 확인한다.

**PCR 프라이머 분석**
1. 표적 DNA 서열을 입력하거나 DNA 분석 페이지에서 전달받는다.
2. 정방향 및 역방향 프라이머의 염기서열을 입력한다.
3. PCR 분석 버튼을 클릭한다.
4. 프라이머의 GC 함량, 간이 Tm, 결합 위치 및 예상 증폭 산물을 확인한다.

**AI 생명공학교사**
1. DNA, BCA 또는 PCR 분석을 수행한다.
2. 분석 결과를 AI 생명공학교사에 전달한다.
3. AI가 참고할 분석 데이터를 선택한다.
4. 채팅창에 분석 결과나 생명공학 개념에 관한 질문을 입력한다.
5. AI가 생성한 설명을 확인하고 필요에 따라 추가 질문을 입력한다.

## 3. 주요 기능 설명

### 3.1. DNA 염기서열 분석

NCBI 데이터베이스와 연동하여 실제 유전자 서열을 검색하고 다양한 생물정보학적 분석을 수행한다.

**주요 기능**
- NCBI API를 활용한 유전자 검색 및 DNA 서열 불러오기
- DNA 길이 및 GC 함량 계산
- 시작 코돈과 종결 코돈을 기반으로 한 ORF 탐색
- 코돈을 아미노산 서열로 번역
- 기준 DNA와 비교 DNA의 서열 정렬
- SNP(염기 치환), Insertion(삽입), Deletion(결실) 탐지
- 변이에 따른 코돈 및 아미노산 변화 예측
- DNA 이중나선 모식도와 변이 위치 시각화

특히 Biopython의 서열 정렬 기능을 활용하여 길이가 서로 다른 DNA 서열도 비교할 수 있도록 구현하였다.

### 3.2. BCA 단백질 정량 분석

BCA Assay에서 측정한 흡광도 데이터를 바탕으로 단백질 농도를 정량적으로 분석한다.

**주요 기능**
- 표준용액 농도 및 흡광도 데이터 입력
- 표준곡선 자동 생성
- 선형회귀를 통한 회귀식 계산
- 결정계수(R²)를 이용한 회귀 적합도 확인
- 미지 시료의 단백질 농도 계산
- 표와 그래프를 통한 분석 결과 시각화

이를 통해 실험 데이터를 수작업으로 계산하는 과정을 줄이고, 정량 분석 결과를 직관적으로 확인할 수 있다.

### 3.3. PCR 프라이머 분석

입력한 DNA 서열과 프라이머 정보를 이용하여 PCR 증폭 가능 구간을 예측한다.

**주요 기능**
- 정방향 및 역방향 프라이머 입력
- 프라이머 길이 및 GC 함량 계산
- Wallace 식을 이용한 간이 녹는점(Tm) 추정
- 표적 DNA에서 프라이머 결합 위치 탐색
- 예상 PCR 증폭 산물의 위치 및 길이 계산
- 프라이머 결합 위치와 증폭 구간 시각화
- 프라이머 길이, GC 함량, Tm 차이에 대한 경고 제공

단, 완전 일치하는 결합 위치를 기준으로 분석하므로 실제 PCR 실험의 성공 여부를 보장하지는 않는다.

### 3.4. AI 생명공학교사

Google Gemini API를 활용하여 생명공학 개념을 설명하고 사용자가 수행한 분석 결과의 해석을 지원한다.

**주요 기능**
- 생명공학 관련 질문에 대한 AI 답변 생성
- DNA, BCA, PCR 분석 결과와 AI 채팅 연동
- 분석 결과를 JSON 형식으로 전달
- 기초·고등학생·심화 수준에 따른 설명
- 선택한 DNA 구간의 실제 염기서열 전달
- AI 대화 기록 확인 및 TXT 파일 다운로드

단순한 질문·답변을 넘어 사용자가 직접 분석한 데이터를 바탕으로 결과의 의미와 한계를 이해할 수 있도록 설계하였다.

AI가 생성한 해석과 예측은 학습 보조용이며, 실제 실험 결과나 생물학적 사실에 대한 별도의 검증이 필요하다.

## 4. 프로젝트의 특징 및 기대 효과

BioLab Analyzer의 가장 큰 특징은 **생명공학 데이터 분석과 AI 기반 학습 기능을 하나의 웹사이트에 통합했다는 점**이다.

사용자는 실제 유전자 서열과 실험 데이터를 직접 분석하고, 결과를 그래프로 확인한 뒤, AI 생명공학교사를 통해 분석 결과에 관한 추가 설명을 얻을 수 있다.

이를 통해 생명공학 분야의 데이터 분석 과정을 보다 쉽게 경험하고, 프로그래밍과 생명과학 지식을 융합하여 문제를 해결하는 능력을 기를 수 있을 것으로 기대한다.

---

## 5. 프로젝트의 한계

- DNA의 ORF 및 단백질 영향 분석은 예측 결과이며 실제 유전자 발현이나 단백질 기능을 확정하지 않는다.
- BCA 분석 결과는 표준곡선의 적합도와 시료 전처리 및 실험 오차의 영향을 받을 수 있다.
- PCR 분석은 완전 일치 결합을 기준으로 하므로 실제 반응 조건과 비특이적 결합 등을 충분히 반영하지 못한다.
- AI 생명공학교사의 답변은 오류가 포함될 수 있으므로 별도의 검증이 필요하다.

본 프로젝트는 생명공학 데이터 분석 및 학습을 목적으로 개발되었으며, 전문적인 연구·의료 판단을 대체하지 않는다.
